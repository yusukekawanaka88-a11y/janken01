①課題名
じゃんけんアプリ ～グー・チョキ・パーでCPUと対戦！～
②課題内容（どんな作品か）
- プレイヤーが「グー」「チョキ」「パー」のいずれかを選び、コンピュータと対戦するシンプルなじゃんけんゲームです。
- コンピュータの手はランダムに決まり、選択した手に応じて「勝ち」「負け」「あいこ」を判定します。
- 対戦結果に合わせて、絵文字付きのメッセージが表示されます。
- 手を選ぶたびに何度でも対戦できます。
③アプリのデプロイURL
未デプロイ
④アプリのログイン用IDまたはPassword（ある場合）
なし
⑤工夫した点・こだわった点
- JavaScriptの`Math.random()`と`Math.ceil()`を使い、コンピュータがランダムに手を出す仕組みを実装しました。
- プレイヤーが選んだ手ごとに`if`文で条件分岐を行い、勝ち・負け・あいこを判定できるようにしました。
- jQueryのクリックイベントを使用し、ボタンを押すだけで対戦が進行するようにしました。
- jQueryの`.html()`を使用して、コンピュータの手・勝敗・メッセージを画面上で切り替えられるようにしました。
- 対戦結果に応じて絵文字付きのメッセージを表示し、遊び心を加えました。
⑥難しかった点・次回トライしたいこと（又は機能）
- プレイヤーが選んだ手とコンピュータの手の組み合わせから、正しく勝敗を判定する条件分岐を考えることが難しかったです。
- クリックした後に複数の表示内容をまとめて更新する処理に苦戦しました。
- 次回は勝敗判定の共通処理を関数にまとめ、重複するコードを減らしたいです。
- HPゲージや勝利時の演出などを加え、よりゲーム性の高いじゃんけんアプリにも挑戦したいです。
